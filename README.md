16.2 — абстрактный класс и миксин

- Создан базовый абстрактный класс **`BaseProduct`** (`abc.ABC`):
  - родитель для `Product`, содержит общую функциональность продуктов:
    инициализацию атрибутов, `__str__`, геттер и сеттер цены с валидацией;
  - создать экземпляр напрямую нельзя — выбрасывается `TypeError`.
- `Smartphone` и `LawnGrass` по-прежнему наследуются только от `Product`
  и наследуют функциональность `BaseProduct` через него.
- Реализован класс-миксин **`CreationLoggerMixin`**: при создании объекта
  печатает в консоль класс и параметры в формате
  `Product('Имя', 'Описание', цена, количество)`.
- Миксин встроен в цепочку наследования первым:
  `class Product(CreationLoggerMixin, BaseProduct)`,
  вывод реализован через магический метод `__repr__`.
- Покрытие тестами — 100% функционального кода.
