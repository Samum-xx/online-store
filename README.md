14.2 add_product, геттеры/сеттеры, new_product
=======
домашка 14.1

Реализованы классы `Product` и `Category` с подсчётом статистики, загрузка данных из JSON, полный набор тестов и проверка линтером (flake8).

## Правки по ревью (HW 14.2)

- Атрибут цены сделан приватным с двумя подчёркиваниями (`__price`),
  геттер и сеттер `price` работают с приватным атрибутом.
- Формат строки геттера `products` соответствует шаблону:
  «Название, X руб. Остаток: X шт.»
